# Profiles Hair Salon - React Application

A sleek, modern high-fashion Hair Salon React JS web application built for Profiles Hair Salon in Grand Ledge, MI.

## Business Details
- **Address:** 315 Harrison St, Grand Ledge, MI 48837
- **Phone:** (517) 627-9800
- **Hours:** Tuesday - Friday: 9:00 AM - 7:00 PM | Saturday: 8:00 AM - 4:00 PM | Sunday - Monday: Closed

## Features
- Dynamic Haircare & Styling Service Price Catalog (Cuts, Balayage, Highlights, Extensions, Scalp Care)
- Hair Transformation Lookbook Gallery with High-Resolution Photography
- Master Stylist Bios & Specialization Showcase
- Interactive Consultation & Appointment Booking System Modal
- Professional Product Brand Partnerships (Redken, Olaplex, Kérastase)
- Location Map, Contact Details & Operating Hours for Grand Ledge
